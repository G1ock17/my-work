Анализ объявлений об аренде недвижимости

О проекте

Проект посвящён исследованию объявлений об аренде жилой недвижимости в Москве, собранных с сайта ЦИАН.

Цель проекта — изучить характеристики объектов недвижимости, исследовать факторы, влияющие на стоимость аренды, выявить закономерности в данных и подготовить датасет для дальнейшего анализа.

Задачи проекта

Провести разведочный анализ данных (EDA).

Изучить структуру и основные характеристики датасета.

Исследовать распределение стоимости аренды и площади объектов.

Проанализировать распределение объявлений по количеству комнат, типам недвижимости и станциям метро.

Выявить пропущенные значения, дубликаты, выбросы и другие проблемы качества данных.

Выполнить предобработку данных и обработать пропуски.

Создать новые признаки (Feature Engineering).

Подготовить итоговый датасет для дальнейшего анализа.

Структура проекта

├── README.md
├── EDA.ipynb
├── EDA.html
├── preprocessing.ipynb
├── data.csv
└── teamname_data.csv

EDA.ipynb — ноутбук с разведочным анализом данных.

EDA.html — HTML-отчёт с графиками и основными результатами EDA.

preprocessing.ipynb — ноутбук с обработкой данных и созданием новых признаков.

data.csv — датасет после обработки пропущенных значений.

teamname_data.csv — итоговый датасет после Feature Engineering.

README.md — описание проекта и его результатов.

Файлы добавляются в репозиторий по мере выполнения соответствующих этапов проекта.

Этапы проекта

Релиз 1.0 — Разведочный анализ данных (EDA)

Изучение структуры датасета.

Анализ распределения числовых и категориальных признаков.

Исследование стоимости аренды и характеристик недвижимости.

Анализ пропущенных значений и дубликатов.

Формирование предварительных выводов о качестве данных.

Релиз 2.0 — Предобработка данных

Обработка пропущенных значений.

Приведение названий столбцов к единому формату на английском языке.

Преобразование данных к необходимым типам.

Сохранение обработанного датасета в data.csv.

Релиз 3.0 — Feature Engineering

Создание новых признаков на основе имеющихся данных.

Подготовка числовых признаков для дальнейшего анализа.

Сохранение идентификатора объявления для сопоставления результатов.

Проверка отсутствия пропусков и полных дубликатов.

Сохранение итогового датасета в teamname_data.csv.

Результаты EDA

Раздел будет дополнен после завершения разведочного анализа.
